# Blinder Vier-Modell-Hörtest

Vergleiche pro Übergang 5 zufällig beschriftete Varianten. Alle Labels einer Zeile verwenden dieselben vier 4-Takt-Stimuli, Cuepoints, Kontextstücke und gemeinsamen Peak-Gain. Bewertungen lokal eingeben und als ratings.json herunterladen; answer_key.json erst danach öffnen.

Wichtig: Der variable Checkpoint ist auf Dataset-v2/Feature Protocol 2 trainiert, während die übrigen drei Modelle Dataset-v1/Feature Protocol 1 verwenden. Seine Features wurden für dieselben Dataset-v1-Validierungs-Cues mit der v2-Trainingsnormalisierung berechnet. Das ist ein explorativer gemeinsamer Stimulusvergleich, kein protokollgleicher oder unabhängiger Generalisierungstest.
