# BeatBridge Agent Instructions

- Read `docs/STATUS.md`, `docs/Projekt-Gesamtuebersicht.md`, and `.agents/AGENT.md` before project work.
- Always read and follow `.agents/multi-session-project-discipline.skill` for work in this repository.
- Treat repository documentation as the persistent project memory; update it when verified milestones, decisions, or dead ends change.
- Dokumentiere jeden ausgeführten Testlauf in `docs/Bemerkungen.md`: Datum, Fragestellung und Reasoning, Eingaben/Setup, Testumfang bzw. Befehl, Ergebnis (einschließlich Fehlern oder Blockaden) sowie Schlussfolgerung und nächsten Schritt. So bleibt nachvollziehbar, was wann und warum getestet wurde.
- Use `.venv\Scripts\python.exe` for Python commands and checks.
- Preserve original audio/data files and existing user changes.
- The user owns commits; agents do not create commits unless explicitly requested.
- When the user explicitly requests a commit, use the repository-configured human Git identity. Never add Codex, an AI agent, or an AI-related `Co-authored-by`/author trailer.
